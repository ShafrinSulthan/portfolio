# 📦 Installation

Clone the repository

```bash
git clone https://github.com/ShafrinSulthan/portfolio.git
```

Go to the project folder

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```

# 🚀 Deployment
